# orientation-quiz
«Академия безопасности: Безопасное ориентирование» — сюжетная браузерная игра для 2 класса. 
В истории «План с поправкой» Мира, Лев и Анна Сергеевна идут на выставку в осеннем сквере, но прямая аллея закрыта на ремонт. Помогите героям прочитать план, определить стороны горизонта, найти ориентиры и проверить открытый обход. В игре 6 остановок, 23 задания, подсказки, блокнот исследователя и 5 иллюстрированных карточек «Если потерялся» для печати. Без таймера и штрафов; прогресс сохраняется в браузере.
